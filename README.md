### 🏭 [Industrial Anomaly Detection & Predictive Maintenance](https://github.com/merkavii/SensorAnomalyDetection)

> End-to-end ML + MLOps platform for multivariate time-series anomaly detection on industrial machinery, built on the **Skoltech Anomaly Benchmark (SKAB)**.

- 🧪 **Leak-free unsupervised training** on clean baseline telemetry
- 🎯 **Root-cause sensor isolation** using Z-score deviations + `IsolationForest` scores
- ⚙️ **Production-style stack:** FastAPI + Pydantic validation, SQLite logging, live Chart.js dashboard, data-drift detection, pytest suite, Docker

`Python` `scikit-learn` `FastAPI` `SQLite` `Docker` `pytest` `CI/CD`

---

### 🔍 [Visual Image Search System](https://github.com/merkavii/VisualSearchSystem)

> Semantic image search that compares *meaning*, not pixels. Images become 512-D **CLIP** embeddings and are retrieved with **FAISS** nearest-neighbor search.

- 📷 Upload an image in a **Streamlit** UI and get Top-K visually similar results with similarity scores
- 🚀 **FastAPI** backend, GPU acceleration with PyTorch (CUDA)
- 🐳 Docker & docker-compose included

`PyTorch` `CLIP` `FAISS` `SentenceTransformers` `FastAPI` `Streamlit`

### 🧠 [Company Knowledge Assistant](https://github.com/merkavii/CompanyKnolwedgeAssistant) &nbsp; ![status](https://img.shields.io/badge/status-in%20progress-orange?style=flat-square)

> A Retrieval-Augmented Generation (RAG) assistant for company knowledge: ingest internal documents, ask questions, and get answers grounded in the retrieved sources, ideally with precise citations. **Under active development 🚧**

```
Ingestion → Text Extraction → Chunking → Embedding → Vector Store → Retrieval → LLM Generation → Answer + Sources
```

| Stage | Status |
|:--|:--|
| Project structure & data models | ✅ Done |
| Text chunker | ✅ Done |
| Embedder & vector store | 🔧 In progress |
| Retrieval, answer generation & citations | 📝 Planned |
| Evaluation set (retrieval & answer quality) | 📝 Planned |
| Hybrid search & reranking | 💡 Exploring |
| FastAPI service, tests, error handling, access control | 📝 Planned |
